# 圖書館陀螺大賽

給圖書館推廣活動、抽獎用的網頁小遊戲。

玩家流程：
1. **打造陀螺**：選名字、顏色、類型（攻擊／防禦／持久／平衡）和代表的台灣原生植物（每種植物都有小知識與特殊技能）。
2. **知識充能**：回答圖書館利用與原生植物題目，答對一題陀螺能量 +8%。
3. **上場對戰**：拉線發射，陀螺在年輪場地中對撞，耐力先歸零者落敗。
4. **抽獎**：獲勝即可抽獎，自動扣除獎品數量。

## 館員設定
右上角「⚙ 館員設定」可修改：
- 獎品清單（每行 `獎品名稱 | 數量`，不寫數量代表不限量）
- 題數、對手強度
- 落敗是否可抽獎、是否需全部答對
- 重設獎品數量與當日統計

設定與剩餘數量存在瀏覽器的 localStorage，活動現場請固定使用同一台裝置。

## 使用方式
只有一個 `index.html`，不需要安裝。可直接用瀏覽器開啟，或用 GitHub Pages 發布成網址。
